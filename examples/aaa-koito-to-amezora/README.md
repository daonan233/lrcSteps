# 恋音と雨空 example

This folder contains a full-length Ogg Opus copy of the locally uploaded AAA song, its Japanese and romanized LRC files, and the application's saved character timing data.

To try it, start the app and upload `track.ogg` with `japanese.lrc` and `romaji.lrc`. The app will run its own alignment; `alignment.json` records the timing result exported from the original local session for comparison.
